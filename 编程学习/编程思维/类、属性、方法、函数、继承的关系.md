# 总关系汇总

> [!NOTE] 总结概括
> 函数是工具；类把「数据(属性) + 工具(方法)」打包；继承让打包好的能力可以传给子类。

```
函数：独立做事的工具

类：模具
 ├─ 属性：对象身上的数据（它有什么）
 └─ 方法：对象身上的函数（它会做什么）

继承：子类模具复用父类模具的属性和方法
```

## 关系图

```
                    ┌──────── 继承 ─────────┐
                    │  复用父类的            │
                    │  属性 + 方法           │
                    ▼                       │
函数 ───────────► 方法（特殊的函数）            │
 独立工具            │                       │
                     │ 写在类里              │
                     ▼                      │
                   类 ◄─────────────────────┘
                   │
                   │ 实例化
                   ▼
                  对象
                   │
         ┌─────────┴─────────┐
         ▼                   ▼
       属性                 方法
     （有什么）           （做什么）
```

#### 方法本质上就是函数，特殊的点在于：

1. 写在类里面
	
2. 第一个参数通常是 `self`（当前对象）
	
3. 用 `对象.方法()` 调用
