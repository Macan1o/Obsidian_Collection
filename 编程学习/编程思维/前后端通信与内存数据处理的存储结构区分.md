> 结合不同对象之间的特性 [[基础八股]] 中的三种对象分类

### 两者的场景范畴

前后端接口传输、本地存储 localStorage /sessionStorage → 只用普通 Object

	JSON 只支持对象、数组、基础类型，Map/Set 直接序列化会丢失内容，必须转数组才能存

拿到后端扁平数组，做映射、频繁增删查询、树形转换、缓存映射 → 优先 Map

	大量数据、高频查找、动态 key，Map 性能和易用性远胜普通对象。

### 完整业务场景举例

```Javascript
// 1. 后端拿到扁平数组（普通对象）
const list = await api.getMenu()

// 2. 中间处理：转Map构建树（Map做临时索引）
const map = new Map()
list.forEach(item => map.set(item.id, {...item, children:[]}))

// 3. 树形处理完成，得到tree数组（内部还是普通对象）
const tree = arrayToTree(list)

// 4. 传给组件渲染 / 提交给后端（只用普通对象数组，Map不参与传输）
renderTree(tree)
```

> 相当于缓存到map对象的高性能载体上
