> [!NOTE] 工具背景
> 通过git clone代码到电脑上，输入python指令`pip3 install .` 将工具安装到本机，并通过脚本上报自己的数据到中心机，中心机汇总数据渲染到对应页面上

> 核心就是推模式（组员电脑主动上报）

## 链路流程

### 读取数据库

通过`hub_payload.py` 组件读取本机 Cursor 存放聊天记录的 sqlite 数据库文件做聚合统计：统计今天你一共多少次提问、调用模型次数、会话数量

生成本地唯一标识 `machine_id` 跟幂等键 `machine_id:今天日期`

	同一天重复执行上报，会覆盖旧数据，不会重复生成多条记录

### 本机发起 HTTP POST 网络请求

通过`hub_client.py` 组件自动补全接口路径，将请求发往中心机

### 中心机处理

中心机器提前运行了服务：`cursor_chronicle --hub‑serve`，持续监听 8790 端口。写入中心机本地数据库文件

### 浏览器打开看板页面

浏览器向中心机发起 GET 请求，中心机只读取自己本地的 hub.sqlite 数据库，SQL 查询：取出这一天**所有组员上报成功的全部行**，后端把多条记录打包返回浏览器前端 JS


## 访问中心机原理

根据`hub_client.py`，Python **标准库 urllib**，不依赖 requests 第三方包。

核心就是通过局域网 TCP 协议，把数据包丢给 `192.168.103.61` 这台机器的 **8790 端口**；
