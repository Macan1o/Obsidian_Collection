#### Android SDK

Android开发工具包，通过引入该工具包来使用Android相关的API

## Android模式和Project模式

- Android模式是基于真实的目录结构被Android Studio转换过的
	
- Project模式才是真实的目录结构
### Project目录下结构
#### .gradle和.idea
Android Studio自动生成的一些文件
#### app
项目中的代码、资源等内容都是放置在这个目录下的
#### gradle
项目构建工具，把你的 Java/Kotlin 代码、资源文件、图片、布局、第三方库，打包编译成可安装的 APK / AAB 安装包
#### gradle.properties
全局的gradle配置文件，在这里配置的属性将会影响到项目中所有的gradle编译脚本。

### app目录下的结构

#### libs
如果你的项目中使用到了第三方jar包，就需要把这些jar包都放在libs目录下，放在这个目录下的jar包会被自动添加到项目的构建路径里。
#### res
存放图片、布局、字符串等资源。图片放在drawable目录下，布局放在layout目录下，字符串放在values目录下
#### AndroidManifest.xml
整个Android项目的配置文件，程序中定义的所有四大组件都需要在这个文件里注册，另外还可以在这个文件中给应用程序添加权限声明。一定要先配置主程序Activity

## Activity专栏

#### Activity

类似于Vue、Tsx这种的页面，必须在AndroidManifest.xml里注册，包含用户界面的组件用于和用户进行交
互。负责页面逻辑（代码，处理点击、跳转、弹窗）；而对应的`first_layout.xml` 专门管**页面长啥样，可以通过`android:id`属性定义元素实例，然后Activity通过`findViewById()`方法获取元素**

定义元素方式`@+id` 意思是新增一个 id，自动写入 R 类的 id 板块

#### Activity中使用Menu

在res目录下新建一个menu文件夹，在`main.xml`定义添加和移除选项。到对应的Activity中重写`onCreateOptionsMenu()`方法

	menuInflater.inflate(R.menu.main, menu)

通过menuInflater语法糖给当前Activity创建菜单，`inflate()`方法接收两个参数：第一个参数用于指定我们通过哪一个资源文件来创建菜单，是传入R.menu.main；第二个参数用于指定我们的菜单项将添加到哪一个Menu对象当中

重写`onOptionsItemSelected()`定义菜单响应事件

#### Intent在Activity应用

类似于路由跳转，通过Intent完成组件之间的交互，并且分为显式Intent和隐式Intent，Intent一般可用于启动Activity、启动Service以及发送广播等场景

##### 显式Intent
只能自己 App 内使用，无法调用系统、第三方软件。语法上直接写死
```kotlin
// 1. 创建快递单，明确目的地：当前页面(this) → SecondActivity
val intent = Intent(this, SecondActivity::class.java)
// 2. 发送快递，执行跳转
startActivity(intent)
```

##### 隐式 Intent
不指定页面，只描述行为，必须同时匹配下面两个原则：

> 在AndroidManifest.xml写好action和category标签

- action：要执行的动作（打开网页、拨号、分享）
	
- category：附加分类（默认自带一条，大部分情况不用改）
    
    可选补充：data 携带数据（网址、手机号）
```kotlin
val intent = Intent(Intent.ACTION_VIEW) // 动作：浏览页面
intent.data = Uri.parse("https://www.baidu.com") // 附带数据：百度网址
startActivity(intent)
```

#### Intent在Activity中传递数据

##### 传数据给下一个Activity

通过`putExtra()`方法存储在键值对中，在下一个页面中通过下面的方式取出来即可

	val extraData = intent.getStringExtra("extra_data")

还有`getIntExtra()`、`getBooleanExtra()`等方法以此类推

##### 传数据给上一个Activity

通过`startActivityForResult()`方法不同于`startActivity()`直接跳转，它期望在Activity销毁的时候能够返回一个结果给上一个Activity

基本逻辑为：

	执行startActivityForResult(intent,1)跳转到 SecondActivity
	创建空 Intent 存放文字，intent.putExtra("data_return", "Hello FirstActivity")塞入数据
	setResult(RESULT_OK, intent)向上一级返回数据，OK代表操作正常完成，CANCEL代表取消操作

父页面重写接收回调方法 `onActivityResult` ，**系统自动调用该方法**
```kotlin
override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    // 判断任务编号
    when (requestCode) {
        // 匹配我们刚才设置的编号1，代表是SecondActivity返回的数据
        1 -> {
            // 判断操作成功
            if (resultCode == RESULT_OK) {
                // 从带回的intent取出字符串
                val returnedData = data?.getStringExtra("data_return")
                Log.d("FirstActivity", "收到返回数据：$returnedData")
            }
        }
    }
}
```

## 常用控件方法

#### TextView
文本内容，通过文档属性进行样式调整
#### Button
按钮组件，通过属性进行样式调整，可以写逻辑
#### EditText
类似于input，允许用户在控件里输入和编辑内容，并可以在程序中对这些内容进行处理
#### ImageView
展示图片的一个控件，图片通常是放在以drawable开头的目录下，可以设置图片宽和高
#### ProgressBar
加载提示控件，通过`visibility`控制显示隐藏「VISIBLE/GONE」，`progress`修改进度数值
#### AlertDialog
类似于弹窗，一般用于逻辑的确认和取消

## 三种基本布局

### LinearLayout「线性布局」

> 所有控件**一条线排列**，只有两个方向：垂直竖排 / 水平横排

- 垂直 vertical（从上往下排，最常用）
	
- 水平 horizontal（从左往右排）

适合登录页、底部导航

### RelativeLayout 「相对布局」

> 控件**不靠固定行列**，以父容器 / 其他控件为参照物摆放。

- 相对父布局：
    `android:layout_centerInParent` 居中
    
    `android:layout_alignParentLeft` 贴左边
    
    `android:layout_alignParentRight` 贴右边
    
- 相对其他控件：
    `android:layout_below="@id/btn1"` 放在 btn1 下方
    
    `android:layout_toRightOf="@id/btn1"` 放在 btn1 右边

适合复杂多控件页面

### FrameLayout 「帧布局」

> 所有控件默认**全部堆在屏幕左上角**，后写的控件盖在先写控件上面，像叠图层。

	bottom 右下角、center 居中、top 左上角。

适合弹窗、图片叠加文字

## WebView的用法

> WebView控件，相当于**内嵌小型浏览器**，不用跳系统浏览器，直接在当前页面展示网页。

先在布局里包裹一个WebView

- `match_parent`：宽高铺满整个手机屏幕，网页全屏展示
	
- `android:id="@+id/webView"`：给控件起标识，后面代码能找到它

再在对应的Activity页面配置关键逻辑代码

``` kotlin
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // 1. 开启JS支持（现在绝大多数网页都依赖JS，不开页面会错乱空白）
        webView.settings.javaScriptEnabled=true
        // 2. 关键配置：网页跳转不跳出App
        webView.webViewClient = WebViewClient()
        // 3. 加载网页地址
        webView.loadUrl("https://www.baidu.com")
    }
}
```

最后只要 App 联网加载网页，必须在`AndroidManifest.xml`最外层`<manifest>`标签里加网络权限

```kotlin
<uses-permission android:name="android.permission.INTERNET" />
```
