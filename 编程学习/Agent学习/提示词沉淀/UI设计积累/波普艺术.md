## Style Rules

# Pop Art (波普艺术) Design System

> 大胆鲜明的波普艺术风格，灵感来自 Andy Warhol 和 Roy Lichtenstein。粗黑轮廓、半色调网点、漫画式对话泡泡、高饱和度色块。适合创意品牌、潮流文化、艺术展示。

## 核心理念

Pop Art 风格来源于 20 世纪 60 年代的波普艺术运动，以 Andy Warhol 和 Roy Lichtenstein 为代表，通过大胆色块、粗黑轮廓和半色调网点创造视觉冲击。

核心理念：
- 粗黑轮廓：所有元素使用粗黑边框强调形状
- 高饱和色块：使用黄、粉、蓝等纯色平涂填充
- 半色调网点：Ben-Day dots 是波普艺术的标志性纹理
- 漫画风格：对话泡泡、动作线条等漫画元素融入界面

设计原则：
- 视觉一致性：所有组件必须遵循统一的视觉语言，从色彩到字体到间距保持谐调
- 层次分明：通过颜色深浅、字号大小、留白空间建立清晰的信息层级
- 交互反馈：每个可交互元素都必须有明确的 hover、active、focus 状态反馈
- 响应式适配：设计必须在移动端、平板、桌面端上保持一致的体验
- 无障碍性：确保色彩对比度符合 WCAG 2.1 AA 标准，所有交互元素可键盘访问

## [FORBIDDEN] 绝对禁止

以下 class 在本风格中**绝对禁止使用**，生成时必须检查并避免：

### 禁止的 Class
- `bg-gradient-to-r`
- `bg-gradient-to-l`
- `bg-gradient-to-b`
- `bg-gradient-to-t`
- `shadow-sm`
- `shadow-md`
- `shadow-lg`
- `shadow-xl`
- `text-gray-300`
- `text-gray-200`
- `rounded-full`
- `border`

### 禁止的模式
- 匹配 `^bg-gradient`
- 匹配 `^shadow-(?!\[)`
- 匹配 `^rounded-full`
- 匹配 `^border$`
- 匹配 `^text-gray-[1-3]`

### 禁止原因
- `bg-gradient-to-r`: Pop Art uses flat color fills, not gradients
- `shadow-md`: Use hard offset shadows: shadow-[4px_4px_0_#000]
- `rounded-full`: Keep shapes angular (rounded-lg max)
- `border`: Borders must be thick: border-2 or border-4

> WARNING: 如果你的代码中包含以上任何 class，必须立即替换。

## 绝对禁止（匹配即拒绝）

以下模式一旦出现，视为风格违规——不找借口，直接重写。

- 使用渐变色（必须是纯色平涂）
- 使用低饱和度/灰色系颜色
- 使用细线条 border（必须 border-2 以上）
- 使用圆角过大 rounded-full（保持 rounded-none 或 rounded-lg）
- 使用极简/无装饰的设计语言
- 使用 `duration-200` 或更长的 hover/active 过渡（波普艺术要求 `duration-100 ease-out` 的冲击速度）
- Ben-Day 纹理只用单层（必须双层叠加才有颜色变换的网点效果）
- hover 只使用 `translate-y` 而不配合 `scale` 和 `rotate`（Comic Pow! 三者缺一不可）
