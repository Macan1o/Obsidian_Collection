### 先进行全局安装

	npx skills add tt-a1i/archify -g

### 使用提示词

##### 场景 A：纯自然语言描述生成（无需本地代码库）

> **Prompt 示例：** “用 Archify 画出：Browser -> API 网关 -> Redis 缓存 -> PostgreSQL 回源，并包含 JWT 认证中间件。”

##### 场景 B：基于当前代码仓库自动逆向架构

> **Prompt 示例：** “分析当前代码仓库，然后使用 Archify 生成一张高层运行时架构图。保留 8~12 个核心模块，突出主要业务请求路径，并标出外部依赖与信任边界。辅助信息放说明卡片中。”

> **通用版Prompt** ：分析当前代码仓库，使用 Archify 生成完整的架构图
