> 它是一套**通用方法论**，目标是操控大模型的推理、输出、行为，覆盖所有模型交互场景：

1. 基础文本控制（纯对话、写作、翻译、总结、逻辑推理）思维链 CoT、少样本 Few-shot、格式约束、幻觉抑制、角色设定、输出长度控制，全程不需要调用工具、不需要 Skill、不需要 MCP。
	
2. 结构化输出设计（JSON/Markdown/ 表格 / 代码）
	
3. Agent / 工具调用语法设计（给模型定义怎么输出工具请求，对接 MCP、Function Call）
	
4. 流程封装（把多轮逻辑打包成模板 → 这一步才产出 Skill）
	
5. 上下文管理、知识库注入、动态 Prompt、提示词安全防注入、提示词优化调优
	
6. 多模型适配（适配 Claude、GPT、开源大模型各自上下文窗口、指令偏好）

#### Skill 是**提示词工程的产物 / 封装载体**，面向固定业务的可复用流程组件
