# 语法逻辑
## A. 类型契约

> 给名字、字段、函数签名立规矩。不改运行逻辑，但决定 IDE 补全和类型检查能不能拦住错。

| 编号  | 语法                                   | 一句话             |
| --- | ------------------------------------ | --------------- |
| 1   | `from __future__ import annotations` | 推迟求值类型注解，少踩循环导入 |
| 2   | `str ｜  None`、`dict[str, T]`         | 现代联合类型 + 内置泛型   |
| 3   | `Literal[...]`                       | 把字符串收成有限集合      |
| 4   | `TypedDict` + `NotRequired`          | 给 JSON/状态袋立字段契约 |
| 5   | `Protocol` + 仅关键字 `*`                | 鸭子类型接口，调用必须点名传参 |
| 6   | `TypeVar`                            | 两条路径返回同一类型      |


[[Clutch类型契约]]

## B. 数据容器

> 把一堆字段收成对象：内部值对象、状态枚举、HTTP 入参。

|编号|语法|一句话|
|---|---|---|
|8|`@dataclass`（`frozen` / `slots` / `field` / `@property` / `@classmethod`）|内部结构体：不可变、省内存、可变默认值|
|9|`str, Enum`|既是枚举又能当字符串|
|10|Pydantic `BaseModel` + `Field`|HTTP 边界校验|

[[Clutch数据容器]]

## C. 生命周期

> 管进程启动/关闭、路由注册、资源加锁解锁、后台任务。

| 编号  | 语法                                                        | 一句话                     |
| --- | --------------------------------------------------------- | ----------------------- |
| 11  | `@lru_cache` / `@contextmanager` / `@asynccontextmanager` | 装饰器：缓存、同步锁、应用寿命         |
| 12  | `async` / `await` / `to_thread` / `create_task` / `Lock`  | 事件循环：让 I/O、别阻塞、后台跑、互斥   |
| 16  | 嵌套函数 / 闭包                                                 | 把实现关在 lifespan 里，捕获外层变量 |

[[Clutch生命周期]]

## D. 写短写稳

> 同一层逻辑写得更紧，出错时因果不断。

|编号|语法|一句话|
|---|---|---|
|13|海象 `:=`|赋值同时当判断条件|
|14|推导式 / `**` `*` 解包 / `defaultdict`|过滤变换、浅拷贝改字段、按 key 分组|
|15|`raise ... from`|包成业务异常，保留底层原因|
