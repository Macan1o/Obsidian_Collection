## 装饰器的概念

	装饰器本身是一个函数，它的作用是在不修改原函数代码的前提下，给原函数增加新的功能。

可以这样理解

> 生产了一个漂亮的玻璃杯（**原函数**），现在你要把它快递给客户。 如果你直接寄，杯子可能会碎。于是你找了快递站的包装小哥（**装饰器**）

- **拿到你的杯子**（接收原函数作为参数）
    
- **包上防摔气泡膜**（执行原函数**前**的额外操作）
    
- **把杯子装进盒子**（执行原函数）
    
- **贴上快递单并发送短信**（执行原函数**后**的额外操作）
    
- **把整个包裹交出去**（返回包装好的新函数）

在这一过程中，玻璃杯本身没有任何改变，但它获得了“防摔”和“通知”的额外功能。


---

## 代码理解

#### 玻璃杯函数

```Python
def say_hello():
    print("你好，世界！")
```

#### 包装函数

```Python
def log_decorator(func):
    # wrapper 就是那个“打包好的新包裹”
    def wrapper():
        print("【日志】准备执行函数...") # 气泡膜（执行前）
        func()                         # 原来的杯子（执行原函数）
        print("【日志】函数执行完毕！") # 发短信（执行后）
    
    return wrapper # 返回包装好的新包裹
```


---

#### 原始方法

```Python
say_hello = log_decorator(say_hello)
say_hello()

# 输出结果：
# 【日志】准备执行函数...
# 你好，世界！
# 【日志】函数执行完毕！
```

#### 使用@语法糖

```Python
@log_decorator
def say_hello():
    print("你好，世界！")

say_hello() # 直接调用，效果和上面完全一样
```


## 装饰器的应用场景

- **权限校验**：比如 `@login_required`，在执行敏感操作前先检查用户是否登录。
    
- **计算耗时**：在函数执行前后记录时间戳相减，用来测试性能。
    
- **缓存结果**：比如 `@lru_cache`，如果输入参数没变，直接返回上次的结果，不再重复计算。
    
- **Web 路由**：比如 Flask / FastAPI 里的 `@app.route('/home')`，用来把 URL 和具体的函数绑定起来。

## 项目中的应用

区别于传统的「**输入函数，返回函数**」模式，而是生成器函数 → `__enter__` / `__exit__` 对象

	拿你的生成器函数，自动生成一个带 __enter__ 和 __exit__ 的类实例，满足 with 协议。

```Python
# workspace_cli_lock.py 第 25-37 行

@contextmanager
def workspace_cli_turn(workspace_path, *, timeout_s, on_waiting=None):
    lock = _get_lock(workspace_path)     # 准备锁
    acquired = lock.acquire(timeout=timeout_s)  # → 变成 __enter__
    if not acquired:
        raise ShellSessionError("timeout")

    try:
        yield                             # ← "锁已拿到，你现在可以干活了"
    finally:
        lock.release()                    # ← "干完了，释放锁" # → 变成 __exit__
```

```
时间 ──────────────────────────────────────────────────►

with workspace_cli_turn(...):       ← 进入
    │
    ├─ yield 之前的代码执行：获取锁
    │
    ├─ yield                       ← 停在这里！把控制权交给 with 块
    │
    │   _run_turn() 执行...         ← with 块里的代码在这个位置插入执行
    │
    ├─ yield 之后的 finally 执行：释放锁  ← with 块结束后自动回来
    │
退出 with                          ← 结束
```
