## 序列解包

### 基础解包

左右两侧元素数量匹配，类似于解构赋值

```Python
a, b, c = [10, 20, 30]
print(a, b, c)  # 10 20 30
```

### 星号`*`可变解包（收集多余元素）

```Python
head, *middle, tail = [1,2,3,4,5]
print(head)    # 1
print(middle)  # [2,3,4]
print(tail)    # 5
```

### `*`用于函数调用：打散序列

```Python
def func(x, y):
    print(x + y)

nums = [2, 3]
func(*nums)  # 等价 func(2,3)
```

## 字典解包（`**`）

`**`只能作用于字典，把键值对打散成 `key=value` 形式

```Python
def func(a, b):
    print(a, b)

d = {"a": 10, "b": 20}
func(**d) # 等价 func(a=10, b=20)
```

## 函数定义中的可变参数

`*args`：收集多余**位置参数**，得到元组

```Python
def demo(a, *args):
    print(a, args)
demo(1,2,3,4) # a=1, args=(2,3,4)
```

`**kwargs`：收集多余**关键字参数**，得到字典

```Python
def demo2(a, **kwargs):
    print(a, kwargs)
demo2(1, b=2, c=3) # a=1, kwargs={"b":2,"c":3}
```

## 注意事项

- 定义函数时 `*args` 必须在 `**kwargs` 前面
	
- 调用时 `*`解包、`**`解包可以混用
	
- `*`不能直接解包字典（只会拿到 key）；字典想要同时取 key 和 value 用`**`
