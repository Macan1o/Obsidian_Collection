#### 项目方面

我做了一款基于 Next.js的全栈实时智能效率协作平台，集成实时 IM、Obsidian式笔记、个人工作台、知识图谱和 multi-Skill AI 助手，并支持 Electron 桌面端 和 PWA。

架构上我按场景做了 双后端拆分：

**会话和好友走 Convex 订阅实现实时消息**，并用 Clerk Webhook + clientId 做用户同步和发送幂等；

笔记、仪表盘和 AI 则走 Next API + Prisma + PostgreSQL，笔记侧用 TipTap 自定义 Wiki 双链和评论标注，关系落在 NoteLink 表，配合反向链接和 D3 力导向图谱。

AI 模块采用 **Skill 插件化编排**，对话用 SSE 流式推送，doc Skill 基于 pgvector + 百炼 Embedding 做 query/document 分离的 RAG，并带向量写入的成本控制；

前端在笔记和仪表盘用 Zustand 乐观更新 + 防抖持久化，聊天用 Convex withOptimisticUpdate，AI 侧用乐观用户消息和流式 commit，笔记列表用 refresh 合并策略 避免覆盖未同步的本地编辑。**整体上体现的是 按领域选型、实时与最终一致并存、以及 AI 与知识库打通的工程实践**
