### 全栈实时智能效率协作平台

#### 旧版

	React +TypeScript + Next.js + PostgreSQL + Convex + Clerk + Cloudinary + Zustand + Tailwind CSS + Prisma + Electron

- 基于 DOM 空间坐标映射重写了编辑器的底部焦点捕获逻辑，实现基于 Y 轴点击深度的动态补行算法，自动清除继承格式并重定向光标，解决焦点死锁和格式残留问题
	
- 完成Convex和Clerk集成，实现多用户鉴权以及实现从MVP到使用Prisma ORM定义数据表结构，通过 B-Tree 索引优化用户数据查询性能的架构升级，完成用户数据隔离以及降低查询时间复杂度
	
- 拦截编辑器原生图文事件，引入基于临时 ID 的Base64 占位秒级预览与异步云端静默上传无感替换策略，实现无阻塞的高效富文本排版体验。采用DOM索引匹配方式实现动态目录提取，解决TOC的同步逻辑引发的IME问题，解决SSR和客户端之间的 Hydration 冲突。
	
- 自定义Blot进行复杂功能定制，并采用继承类的方式，设计兜底机制。并采用序列化与反序列化及DOM 属性中转解决Quill底层数据模型指针冲突问题。
	
- 搭建 Electron 桌面应用架构，内嵌 Next.js 独立服务；修复 Prisma 二进制引擎丢失、符号链接悬空、子进程环境变量隔离问题，优化桌面端全栈打包与数据库连接稳定性。
