## **整体架构一览**

```
┌─ 数据层 (ProseMirror Doc) ──────────────────────────────────────┐
│                                                                  │
│  collapsibleSection { level: 1|2|3, collapsed: true|false }      │
│    ├─ collapsibleTitle (inline*)          ← 标题行               │
│    └─ collapsibleBody (block+)             ← 正文区               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────────┐
        ▼                   ▼                       ▼
   NodeView DOM         CSS 样式               工具栏状态
   (addNodeView)     (TableStyles)        (EditorToolbar)
```

折叠块在数据结构上是 **3 个 TipTap Node** 的嵌套组合。外层 `collapsibleSection` 包裹标题 `collapsibleTitle` 和正文 `collapsibleBody`。

## 完整交互时序图

```
用户点击「折叠 H1」按钮
  │
  ▼
EditorToolbar: editor.chain().focus().insertCollapsibleSection(1).run()
  │
  ▼
CollapsibleBlock.ts — insertCollapsibleSection(1)
  ├─ findCollapsibleSection($from) → null（不在现有折叠块内）
  ├─ chain().insertContent({ type:"collapsibleSection", attrs:{level:1, collapsed:false}, content:[...] })
  │   └─ ProseMirror 在文档中插入三个嵌套节点
  └─ setTextSelection(titlePos) → 光标定位到标题
  │
  ▼
addNodeView 被调用
  ├─ 创建 dom (div.collapsible-section-level-1)
  ├─ 创建 toggle 按钮 (▾)
  ├─ 返回 contentDOM (div.collapsible-section-inner)
  └─ ProseMirror 在 contentDOM 内渲染 collapsibleTitle + collapsibleBody
  │
  ▼
用户输入标题文字 "第一章"
  │
用户按 Enter → 光标跳到正文区
  │
用户输入正文...
  │
用户点击 toggle 按钮 (▾)
  │
toggle.click → tr.setNodeMarkup(pos, undefined, { ...attrs, collapsed:true })
  ├─ syncDom() → dom.dataset.collapsed = "true"
  ├─ syncToggle() → toggle.textContent = "▸"
  └─ CSS: [data-collapsed="true"] .collapsible-body { display: none }
  │
用户保存 → Note.content 写入 PostgreSQL（完整的 TipTap JSON）
```

当我点击工具按钮的时候先在文档中插入三个嵌套节点，然后将光标定位到标题，此时创建DOM结构包括toggle按钮。

## **1. 节点定义层（**`CollapsibleBlock.ts`**）**

### **1.1 三个节点**

| 节点                   | 类型       | 允许的子内容                                 | 作用                                 |
| -------------------- | -------- | -------------------------------------- | ---------------------------------- |
| `CollapsibleSection` | `block`  | `collapsibleTitle` + `collapsibleBody` | 外层容器，携带 `level` 和 `collapsed` 两个属性 |
| `CollapsibleTitle`   | `inline` | 纯内联内容（文字/标记）                           | 标题行，Backspace 在空标题时触发解包            |
| `CollapsibleBody`    | `block`  | 任意块级节点（段落/列表/嵌套折叠块…）                   | 正文区，折叠时 CSS 隐藏                     |

### **1.2 属性**

```typescript
// CollapsibleSection.addAttributes()
{
  level:    1 | 2 | 3,   // 对应 h1/h2/h3 的字号层级
  collapsed: true | false  // 折叠状态
}
```

## **2. 指令层（Commands）**

### **2.1 插入折叠块** `insertCollapsibleSection(level)`

```typescript
// CollapsibleBlock.ts 第 217-261 行
insertCollapsibleSection: (level) => ({ chain, state }) => {
  // 分支 1：光标已在折叠块内 → 不插入新节点，只改当前块的 level
  const existing = findCollapsibleSection(state.selection.$from);
  if (existing) {
    return chain().command(({ tr }) => {
      tr.setNodeMarkup(existing.pos, undefined, { ...existing.node.attrs, level });
      return true;
    }).run();
  }

  // 分支 2：正常插入
  return chain()
    .insertContent({
      type: "collapsibleSection",
      attrs: { level, collapsed: false },
      content: [
        { type: "collapsibleTitle", content: [] },          // 空标题
        { type: "collapsibleBody", content: [{ type: "paragraph" }] }  // 带一个空段落
      ],
    })
    .setTextSelection(titlePos)  // 光标自动定位到标题
    .run();
}
```

**关键设计**：同一按钮在光标已在折叠块内时是"转换层级"，不在时是"新建"。类 Notion 的行为。

## **4. DOM 渲染层（addNodeView）**

### **4.1 手动构建的 DOM 结构**

```html
<div class="collapsible-section collapsible-section-level-{n}" data-collapsed="true|false">
  <div class="collapsible-section-header">          ← 手动创建
    <button class="collapsible-section-toggle">▾</button>  ← 手动创建
  </div>
  <div class="collapsible-section-inner">           ← contentDOM（ProseMirror 管理）
    <div class="collapsible-title">标题文字</div>    ← ProseMirror 渲染 CollapsibleTitle
    <div class="collapsible-body">正文...</div>      ← ProseMirror 渲染 CollapsibleBody
  </div>
</div>
```

**关键点**：标题和正文在 `contentDOM`（`.collapsible-section-inner`）内部由 ProseMirror 自动渲染，而折叠按钮和 header 是 `addNodeView` 手动创建的 DOM，在 contentDOM 之外。

### **4.2 折叠按钮的点击处理（第 383-432 行）**

```typescript
toggle.click → {
  1. 判断光标是否在折叠块内部 (isSelectionInside)
  2. 记录所有外层父容器当前滚动位置 (scrolledParents)
  3. 执行 tr.setNodeMarkup 切换 collapsed 属性
  4. 如果折叠 + 光标在内部 → 光标移到标题 (pos+1)
  5. 安全聚焦 (preventScroll: true)
  6. requestAnimationFrame → 恢复所有外层容器滚动位置
     ↑ 核心防御：折叠时 DOM 高度突变导致浏览器乱滚
}
```

### **4.3 空正文点击自动聚焦标题（ProseMirror Plugin, 第 312-348 行）**

## **5. 样式层（TableStyles.tsx）**

### **5.1 标题字号（**`>` **子代选择器，防止嵌套穿透）**

```css
/* 第 129-140 行 */
.collapsible-section-level-1 > .collapsible-section-inner > .collapsible-title { font-size: 2rem; }
.collapsible-section-level-2 > .collapsible-section-inner > .collapsible-title { font-size: 1.6rem; }
.collapsible-section-level-3 > .collapsible-section-inner > .collapsible-title { font-size: 1.3rem; }
```

**为什么用** `>` **而不是空格**：见 `开发文档/16-补-折叠块嵌套缺陷修复全链路.md`。空格后代选择器在嵌套时会穿透到内层折叠块，`>` 只匹配直接子级。

### **6.2 高亮状态（最深节点嗅探, 第 186-198 行）**

```typescript
const getDirectCollapsibleLevel = () => {
  if (!editor) return null;
  const { $from } = editor.state.selection;
  for (let d = $from.depth; d > 0; d--) {    // 从光标最深位置向上
    const node = $from.node(d);
    if (node.type.name === "collapsibleSection") {
      return node.attrs.level;  // 遇到第一个就停！
    }
  }
  return null;
};
```

**为什么不用** `editor.isActive`：Tiptap 原生的 `isActive` 扫描整条祖先链（不停止），嵌套时光标在内层 level-1，外层 level-2 也会被命中，导致 H1 和 H2 按钮同时亮。这个自定义函数在遇到第一个折叠块时就返回，只报告最内层的层级。
