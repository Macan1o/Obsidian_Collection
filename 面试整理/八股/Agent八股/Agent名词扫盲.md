#Agent名词概念

---
## 基础概念

#### RAG（检索增强生成）
通过外挂数据库的方式，让数据库相关精确内容作为上下文传给模型，再让模型回答，减少幻觉
#### Function Calling / Tool Calling
模型精准调用外部工具的能力。后端写好一个函数的描述（名字、参数、功能），传给模型，模型返回 JSON 指定要调用的函数，后端解析后执行。
#### MCP
模型上下文协议，统一大模型接入工具和数据源的方式。只要工具按照MCP标准暴露能力，就能读取对应工具的接口，完成不同工具与大模型的交互
#### Skill
**Skill 把一套固定能力打包封装（指令 + 工具 + 资源 + RAG）**，做成可复用模块，避免重复开发
