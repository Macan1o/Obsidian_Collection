# Node前置知识

## Node.js与传统服务器后端语言有何区别

Node.js是基于Chrome V8引擎的JS环境运行的，与其他后端语言相比，Node.js基于**事件驱动和非阻塞I/O模型**，更适合处理高并发、I/O密集型任务。

## require函数的作用

用于在node.js中引入模块，加载内置模块、第三方模块和自定义模块。

## Node.js的事件循环机制

事件循环是Node.js处理异步操作的核心机制。它会不断检查事件队列，当有事件到达时，将其分配给相应的回调函数执行。Node.js在执行完当前轮次的所有同步任务后，会去处理事件队列中的异步任务，实现了**非阻塞 I/O操作**，提高了程序的性能和效率。

## Express框架的核心功能

核心功能包括：**路由系统**、**中间件机制**、**请求和相应处理**等功能

## Node.js与前端框架的交互方式

前端框架通过AJAX或fetch等方式向后端的Node.js服务器发送HTTP请求，Node.js接收请求后进行处理，如查询数据库等操作，然后将结果以JSON等格式返回给前端，前端根据返回数据更新页面。

## 性能优化方式

- 对于一些数据量比较大的情况下，使用缓存。内存缓存或者Redis缓存。
    
- 对代码进行优化，避免不必要的计算和循环。
    
- 合理配置接口参数，按照业务逻辑采用对比更新、全量替换等逻辑来释放传输负载。
    

## Node.js单线程如何处理并发

主循环是单线程的，异步调用都由libuv库管理

# Next框架

## 与React的区别

React 是一个 UI 库，而 Next.js 是一个完整的 Web 应用框架。在React基础上增加了很多实用功能，比如**自动路由**、**服务端渲染**、**数据获取方式**以及**性能优化**等

### 自动路由

只需要在文件夹里创建一个文件，这个文件就会自动变成一个网页地址。不需要配置复杂的路由规则，配置动态路由也很方便

### 服务端渲染

些页面可以在服务器生成（SSR），这样对 SEO 更友好；有些页面可以在构建时生成静态页面（SSG），这样加载速度会非常快；还有一些页面可以继续使用客户端渲染（CSR）。

### 后端能力

内置服务端，可以处理后端请求
