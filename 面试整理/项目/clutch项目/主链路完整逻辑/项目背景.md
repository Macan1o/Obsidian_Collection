
---
我做得这款应用是基于面向开发者的**桌面端多 Agent 编排与监督控制台**。用户通过拖拽画布定义 SOP 工作流，系统自动调度本地 CLI 工具和 MCP 服务协同执行，在统一的 Chat + Terminal + Diff + Flow 控制台中全程监督每个 Agent 的产出，并在关键节点进行人工审批。

之前公司的人员曾经搭建过工作流但是有几个问题就是单Agent上下文首先以及节点协作黑盒，流程逻辑是隐式写在 prompt 里的，难以修改。并且状态可视化也不是很直观。因此我设计了这个基于LangGraph的应用。可以执行更复杂的业务节点逻辑，并且支持状态流转。

整体架构层面我做了三层架构设计，桌面的Tauri负责启动窗口和后端Sidebar以及一些原生相关能力。保证本地CLI能够正常运行；前端采用React编排画布并进行JSON配置，严格只渲染 WebSocket 推来的 ClutchState。后端采用FastAPI + LangGraph，以LangGraph 为唯一编排 SSOT作为全局状态机，通过策略模式是否进入长驻 bash PTY 管理
