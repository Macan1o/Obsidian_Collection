## 连接工具

```
扫盘发现二进制（如 /opt/homebrew/bin/claude）
        ↓
你点「连接工具」
        ↓
POST /api/tools/connect
        ↓
把 "claude-cli" 写进磁盘 JSON 的 connected 列表
```

## 从发消息到跑起来

```
Chat 选 Claude Agent / 工作流 agent_task
        ↓
route_engine 看 agentType（如 claude-cli）
        ↓
tool_available_for_routing：二进制还在 + 已 connected
        ↓
resolve_tool_binary → 拿到真实路径  # 找到Claude二进制文件的路径
        ↓
Hybrid：往保活 bash 里写  claude -p "你的话"
或 Legacy：subprocess 新起一次 claude
```

## 输出回来

```
CLI 往 stdout 打字  # 标准输出 CLI的嘴巴
        ↓
Hybrid：从 PTY 读到结束标记，再解析出正文
Legacy：等子进程结束，收 stdout
        ↓
EngineResult(output, logs)
        ↓
chat_runner 写进 ClutchState
        ↓
WebSocket state_patch → 前端聊天气泡
日志走 Terminal（on_log）
```
