## 逻辑分支

### Workflow 跑到 agent_task

|顺序|条件|走哪条|
|---|---|---|
|1|clutch + 图/视频模型|多媒体路由|
|2|`ollama-cli` 且已连接|Ollama HTTP|
|3|其它 CLI 且工具可用|Hybrid Shell 优先，不行再 legacy 子进程|
|4|想用 CLI 但没装|记日志，回退云端/本地 LLM|
|5|默认（含普通 clutch 文本）|Settings 里的 Completions（云端 LLM 等|

### Chat 发消息

```
Chat 发消息
  → chat_runner
  → route_engine(agent_name=当前选中 Agent, source="plain_chat"/…)
```
