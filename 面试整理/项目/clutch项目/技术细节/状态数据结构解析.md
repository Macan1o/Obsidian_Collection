### 两种字段的总览

```
                    run_id（主键）
                         │
     ┌───────────────────┼───────────────────┐
     ▼                   ▼                   ▼
ClutchState         CompilerState      GraphState（演示）
（UI SSOT）         （工作流托盘）       （最小 4 字段）
     │                   │
     │◄── project ───────┘
     │
     ├─ states/{run_id}.json
     ├─ WS /ws/runs/{run_id}
     ├─ checkpoint thread_id=run_id
     └─ shell_snapshots/{run_id}.json
            └─ 内含 cli_session_id（字段）
```
