# **全局启动链路**

## **业务页共用**

```
打开站点
  → app/layout.tsx
      ThemeProvider → ConvexClientProvider(Clerk + Convex + Authenticated 门控)
      → TooltipProvider + Toaster
  → 进入 app/(root)/*
      → StoreProvider(Clerk useUser)
          → init: dashboardStore / notesStore / foldersStore
          → 并行 GET /api/dashboard/*、/api/notes、/api/folders
      → SiderbarWrapper + 子路由页面
```

|   |   |   |
|---|---|---|
|**层级**|**文件**|**作用**|
|认证门控|`providers/ConvexClientProvider.tsx`|未登录只显示 Loading；`Authenticated` 后才渲染业务|
|数据预热|`store/StoreProvider.tsx`|同一 `user.id` 初始化三个 Prisma 系 Store|
|用户同步聊天侧|`convex/http.ts`|Clerk Webhook → Convex `users` 表（`clerkId`）|

## **Notebook：笔记 + 文件夹**

### **前端**

```
notebook/[noteId]/page
  → useNotes() / useFolders()  （hooks 薄封装）
  → notesStore / foldersStore   （Zustand）
  → NoteEditor
       TipTap + WikiLink + 评论 + TOC + Cloudinary 图
       debounceSave → updateNote
```

|   |   |   |
|---|---|---|
|**Store**|**init**|**写**|
|`notesStore`|`GET /api/notes/[userId]`|POST 新建；PATCH 防抖（按 noteId 合并）；DELETE|
|`foldersStore`|`GET /api/folders/[userId]`|**整树 PUT** 防抖（全量替换）|

### 后端

**更新**

```
PATCH /api/notes/[userId]/[noteId]
  → 更新 Note 字段
  → 若 content 变：事务内 syncLinks（Wiki 出链）
  → 若 title/content 变：fire-and-forget upsertNoteEmbedding（RAG 向量）
```

**新建**

```
createNote（客户端生成 id）
  → 乐观插入 notesStore
  → POST /api/notes/[userId]
  → 服务端 create + void upsertNoteEmbedding
```

## **Wiki 双链 + 反向链接 + 知识图谱**

### **双链**

|   |   |   |
|---|---|---|
|**步骤**|**前端**|**后端**|
|插入链接|`[[` → `WikiLink` 节点 `{id, label}`|—|
|保存正文|`onUpdate` → PATCH `content`|`extractWikiLinkIds` → `syncLinks` → `NoteLink`|
|正向跳转|`WikiLinkNodeView` → `/notebook/[id]`|—|
|反向链接|`BacklinksPanel` → `useBacklinks`|`GET /api/links/[noteId]`（`targetId = 当前`）|
|改标题|`syncWikiLinkLabels` 批量 PATCH 其他笔记 `content`||

### **知识图谱**

|   |   |   |
|---|---|---|
|**路径**|**前端**|**后端**|
|`/notegraph`|`useGraph` → `NoteGraph`（D3）|`GET /api/graph/[userId]`|

```
graph API
  → notes（排除 Daily 文件夹子树）→ nodes
  → NoteLink 全量 → edges（source→target）
  → 点击节点：router.push + folderExpandStore 展开路径
```

## 用户体验

```
登录 → Clerk → Convex Authenticated + StoreProvider.init
仪表盘 → 勾任务 → debounce PUT tasks
笔记 → 写正文、插 [[ 链到另一篇 → PATCH content + syncLinks
打开被链笔记 → GET /api/links 看反链
图谱 → GET /api/graph 浏览关系网
聊天 → Convex 订阅收消息 → message.create 发送
通话 → GET /api/livekit → 进房间
AI doc → SSE 流式回答 → RAG 读笔记向量 → 自动保存 → note_created 更新笔记列表
```
