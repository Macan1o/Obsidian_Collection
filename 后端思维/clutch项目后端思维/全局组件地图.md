# 怎么读（建议顺序）

1. **先 §1–§4**：建立「请求 → 编排 → 执行 → 状态」心智模型（文件头已有傻瓜注释）
	
2. **改设置 / 模型**：再看 §5 的 `settings`/`models` + §11
	
3. **Hybrid 桌面模式**：再看 §7
	
4. **加工具 / MCP**：§3 入口 + §6 零件 + §8
	
5. **Design / 原型**：§4 + §12

	用到某个能力时：在本文件搜关键词 → 打开对应 `.py` 顶部导读（若有）或函数名搜索。

> **记一句：** 主干定故事 · 手脚干具体事 · 基建保驾护航 · 并列线是另一扇门。

```
用户 / React
    │  HTTP + WebSocket
    ▼
main.py + routes/*          ← 门面
    │
    ├─► chat_runner / compiler / engine_router   ← 主干
    │         │
    │         ├─► llm / adapters / builtin_tools / mcp_* / workspace …  ← 手脚
    │         └─► state + run_state_store          ← 真相与落盘
    │
    ├─► design / iue / preview / video_*         ← 并列线
    └─► sidecar_auth / storage / preferences …   ← 基础设施
```
