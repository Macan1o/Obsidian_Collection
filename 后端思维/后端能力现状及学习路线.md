## 阶段一

> 深耕 Node.js/ TypeScript 后端（NestJS）

	看懂后端完整链路，独立写 CRUD 服务，理解底层 IO、事件循环、服务基础性能问题

- <font color="#b7dde8">原生 Node 核心查漏补缺（不要直接上框架）</font>
    
    - 事件循环、同步 / 异步、流 Stream、Buffer、文件读写、进程、子进程；
	    
    - http 模块手写简易服务，理解请求 / 响应完整生命周期；
	    
    - 模块化 CommonJS / ESM 区别，包管理、缓存机制；
    
- <font color="#b7dde8">数据库基础（全栈必备）</font>
    
    - SQL：MySQL，基础增删改查、联表、索引、事务；
	    
    - ORM：Prisma（TS 友好，前端最适配）；
	    
    - 缓存：Redis 基础使用（字符串、哈希、过期淘汰）；
    
- <font color="#b7dde8">中间件基础</font>
    
    Express 完整过一遍：中间件原理、路由分层、错误捕获、请求校验。

### 刷题思路

只刷简单数组、字符串、哈希表（前端基础算法）

## 阶段二

> 学习企业级框架，学习标准后端分层思想，进一步熟悉工程架构

- 分层架构：Controller（接口层）→ Service（业务层）→ Repository（数据层）；
	
- 依赖注入 DI、模块划分、微服务基础思想；
	
- 标准化能力：全局拦截器、过滤器、管道校验、统一返回格式、日志；
	
- 工程化：环境变量分离、配置管理、Swagger 接口文档、单元测试 Jest；
	
- 业务场景：文件上传、鉴权 JWT、RBAC 权限、定时任务、消息队列 BullMQ；
	
- 性能入门：接口超时、分页优化、避免 N+1 查询、数据库索引优化。

### 刷题思路
- 中等难度：链表、双指针、栈、队列、二叉树；
    - 高频工程算法：滑动窗口、前缀和、贪心；
        理由：后端业务大量用到分页、批量处理、数据聚合，这些算法直接提升业务编码能力。

## 阶段三

> 后端性能、服务架构进阶

	懂设计思路，解决不懂性能优化、复杂架构的短板

- <font color="#b7dde8">服务性能优化</font>
    
    - Node 内存泄漏排查、事件循环阻塞定位；
	    
    - 数据库优化：索引、慢查询、分表、读写分离概念；
	    
    - 缓存策略：多级缓存（本地内存 + Redis）、缓存击穿 / 雪崩解决方案；
    
- <font color="#b7dde8">运维 & 部署基础（全栈必考）</font>
    
    - Docker 基础、服务打包、环境分离、简单 Nginx 反向代理、静态资源缓存；
    
- <font color="#b7dde8">分布式基础概念（理解即可，不用手写）</font>
    
    消息队列、限流、熔断、分布式锁、跨域、跨服务调用。

### 刷题思路

- 高频面试后端算法：LRU 缓存、限流算法、拓扑排序、简单动态规划；
	
- 同时搭配系统设计题（手写限流、手写缓存、设计短链接），这是全栈面试区分度最高的内容。
