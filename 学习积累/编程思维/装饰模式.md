## 装饰器的核心思想

> 在**不修改原有函数 / 对象代码、不改动调用方式**的前提下，给它额外增加功能。

Python专门对其优化成了语法糖

在Python中装饰器不仅能装饰函数输出新的函数，还可以装饰协议规范如`with`

```Python
def log(func):
    def wrapper(*args, **kwargs):
        print("执行前")
        return func(*args, **kwargs)
    return wrapper

@log
def hello():
    print("hello")
```


JS中类装饰器概念

```Javascript
function log(fn) {
  return function(...args) {
    console.log("执行前");
    return fn(...args);
  }
}
const hello = log(() => console.log("hello"))
```
