> 包装函数 = 给原函数**附加额外逻辑**（计时 / 自删 / 日志 / 异常捕获）

#### 通过内部封装函数的方式，让原函数逻辑更纯净，以订阅发布once事件举例：

	如果不包装直接写逻辑

```javascript
once(event, cb) {
  this.on(event, cb);
  // 想执行完删掉cb，但这里根本做不到！
}
```

#### 会发现没有执行完删掉自己的逻辑

	如果直接在回调里执行off逻辑

```javascript
once(event, cb) {
  this.on(event, (...args) => {
    cb(...args);
    this.off(event, cb); // ❌ 无效
  })
}
```

#### 数组里存的是箭头函数，不是原始 `cb`，`off` 是通过**全等匹配函数**删除，依然会多次执行

#### 因此对于专门的复杂逻辑：先执行、执行完立刻删除可以封装内部函数

```javascript
const onceWrap = (...args) => { cb(...args); // 1. 先执行用户真正的回调 
this.off(event, onceWrap); // 2. 删除自己 } 
this.on(event, onceWrap); // 3. 存入事件数组
```

#### 直接将内部函数存到数组中，从而off可以正确匹配到事件


### 整体逻辑梳理

其实逻辑很简单，如果不加off函数的话没法执行完成后取消订阅自己，如果用箭头函数执行回调的话，off逻辑无法匹配到，因此需要用到变量接住函数引用也就是封装一层业务逻辑的具名函数注册到事件中，才能被off函数正确匹配到。
